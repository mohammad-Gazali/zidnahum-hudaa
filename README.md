## Introduction

A management system for Masjid (Muslim house of worship). Backend is built on [Django](https://www.djangoproject.com/) + [Django Rest Framework](https://www.django-rest-framework.org/) (SQLite, JWT auth, drf-spectacular schema); frontend is a single [Angular](https://angular.dev) app covering both the public client (`/`) and the admin dashboard (`/admin`), with an API client generated by orval from the live schema.

## Requirements

- Python 3.14 or bigger.
- Node.js in your system.
- [Bun](https://bun.sh) package manager for the frontend.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mohammad-Gazali/zidnahum-hudaa.git
   ```

2. Install dependencies:
   ```bash
   uv sync
   bun install --cwd frontend
   ```

3. Perform migrations:
   ```bash
   make migrate
   ```

## Usage

To start the development server, run:
```bash
make
```

Access the app in your web browser at `http://localhost:8000` (client at `/`, admin dashboard at `/admin`). For the frontend in development mode, run `ng serve` inside `frontend/`.
