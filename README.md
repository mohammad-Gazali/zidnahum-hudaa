## Introduction

A management system for Masjid (Muslim house of worship). Backend is a [Django](https://www.djangoproject.com/) 6 + [Django Rest Framework](https://www.django-rest-framework.org/) monolith (Python 3.14, SQLite, JWT auth, drf-spectacular schema); frontend is a single [Angular](https://angular.dev) app covering both the public client (`/`) and the admin dashboard (`/admin`), with an API client generated by orval from the live schema. Ships with a multi-stage [Docker](https://www.docker.com) setup (Gunicorn + Traefik) for deployment.

## Requirements

- Python 3.14 or bigger.
- Node.js in your system (>= 22.22.3 for the Angular 22 CLI).
- [Bun](https://bun.sh) package manager for the frontend.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mohammad-Gazali/zidnahum-hudaa.git
   ```

2. Install dependencies:
   ```bash
   uv sync
   bun install --cwd frontend
   ```

3. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

4. Perform migrations:
   ```bash
   make migrate
   ```

## Usage

To start the development server, run:
```bash
make
```

Access the app in your web browser at `http://localhost:8000` (client at `/`, admin dashboard at `/admin`). For the frontend in development mode, run `ng serve` inside `frontend/`.

Other `make` targets: `make test` (backend tests), `make build` (compiles the Angular app and collects the static files Django serves), `make shell`, `make migrations`, `make points` (exports points to `exported_points.xlsx`), `make reset-data`.

## Deployment (Docker)

The repo includes a multi-stage `Dockerfile` (frontend built with `ng build` inside the builder stage, served by Gunicorn in a slim runtime stage) and a `docker-compose.prod.yml` with a `web` (Gunicorn) service behind a Traefik reverse proxy. `/static/` is served by Whitenoise and `/media/` by Django, so Traefik only proxies. TLS with Let's Encrypt is always on: requests to :80 redirect to HTTPS on :443. Set `ALLOWED_HOST` in `.env` to the public domain (the certificate is issued for it) and `ACME_EMAIL` to the Let's Encrypt account.

Copy `.env.example` to `.env` (gitignored), then:

```bash
docker compose up --build
```

The app is then available over HTTPS on port 443. SQLite (`db.sqlite3`), media/uploads, and ACME certs persist in Docker named volumes (`sqlite_data`, `media_data`, `acme_data`).
